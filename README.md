# Repton Map Creator
Public facing repository for Repton Map Creator.<br>
No publically available source code for this because it contains code that Superior Interactive have asked me not to reveal. So, this repository is purely here as a home to the binaries.<br>
<br>
See also:<br>
<a href="https://www.reptonresourcepage.co.uk">Repton Resource Page</a><br>
https://github.com/geraldholdsworth/ReptonInfinityBlueprint : Repton Infinity BluePrint<br>
https://github.com/geraldholdsworth/ReptonMapDecoder : Repton Map Decoder<br>

Please note that Repton Map Creator will only open PC Repton 1,2 or 3 data files if the unlocking password has been supplied. This is a requirement from Superior Interactive.
